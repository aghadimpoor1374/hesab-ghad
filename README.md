# حساب قدیم — بسته آماده GitHub

این مخزن سورس ساخت نصاب ویندوز است، نه نصاب آماده و نه نسخه تأییدشده برای اطلاعات اصلی مغازه.

## ساخت نصاب
1. یک مخزن **خصوصی** در GitHub بسازید.
2. محتوای این ZIP را مستقیم در ریشه مخزن قرار دهید؛ `source/` و `setup.iss` و `.github/workflows/windows-installer.yml` باید در ریشه باشند، نه زیر یک پوشه اضافی.
3. اگر پوشه مخفی `.github` بارگذاری نشد، Add file → Create new file را بزنید و مسیر `.github/workflows/windows-installer.yml` را بسازید و متن فایل داخل ZIP را در آن قرار دهید.
4. Actions → Build Windows Installer → Run workflow.
5. بعد از موفق شدن اجرا، Artifact با نام `HesabGhadim-Setup-Win10` را دانلود و از ZIP خارج کنید.
6. فایل `HesabGhadim-Setup-Win10.exe` نصاب است. ابتدا روی کپی اطلاعات آزمایش کنید.

## انتخاب سکه و طلای آبشده
در فهرست «نوع طلا» در هر دو فرم ورود و خروج، علاوه بر طلای نو و دست‌دوم، این گزینه‌ها اضافه شده‌اند:
- طلای آبشده
- سکه (در فرم مخصوص می‌توانید امامی ۸۶، بهار آزادی ۸۶، نیم، ربع یا پارسیان را انتخاب کنید)
- سکه پارسیان

با انتخاب این گزینه‌ها، فرم «سکه، آبشده و حساب دوگانه» با نوع و جهت معامله انتخاب‌شده باز می‌شود. فهرست فرم اولیه به انتخاب قبلی برمی‌گردد تا آبشده یا سکه اشتباهاً به‌عنوان طلای نو ثبت نشود. چیزی خودکار ثبت نمی‌شود. در فرم مخصوص تعداد، وزن واقعی، مبنای وزن، عیار، نرخ و طرف حساب را بررسی و محاسبه و ثبت کنید. موجودی این بخش مستقل است؛ سوابق قدیمی تغییر داده یا بازطبقه‌بندی نمی‌شوند.

## حفظ اطلاعات
پیش از نصب یا تعویض نسخه از همه اطلاعات و پیوست‌ها پشتیبان بگیرید. `hesab_ghadim_files` و `gold_accounting.sqlite3` را حذف نکنید.
دیتابیس، پیوست، اطلاعات مشتری، فایل‌های Excel کد فعال‌سازی، پشتیبان‌ها و کلید خصوصی امضا نباید در GitHub قرار بگیرند. این ZIP فاقد آنهاست. کلیدهای عمومی برای بررسی امضا داخل سورس لازم‌اند و محرمانه نیستند.
ابزار `package_desktop_update.py` برای ناشر است؛ ساخت نصاب به کلید خصوصی نیاز ندارد، اما ساخت بسته به‌روزرسانی امضاشده به کلید خصوصی اصلی نیاز دارد. کلید جدید برای کاربران قدیمی تولید نکنید.

## محدودیت اعتبارسنجی
تست ساخت و انتخاب فرم، به معنی تأیید کامل حسابداری نیست. هشت مغایرت گزارش‌شده قبلی در تست‌های سود/سوابق قدیمی در این تغییر رفع نشده‌اند. تست‌های متمرکز Actions جایگزین کل مجموعه تست نیستند.
نصاب جدید باید در GitHub ساخته شود؛ نصب، چاپ، نمایش آیکن و بازگشت واقعی روی ویندوز هنوز تأیید نشده است. به‌روزرسانی، بازگشت خودکار ندارد؛ UPDATE-FA.txt را بخوانید.

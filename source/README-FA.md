# حساب قدیم — راهنمای نصب و استفاده

برنامهٔ رومیزی حسابداری طلا با رابط فارسی؛ وزن‌ها **گرم** و مبالغ **تومان** هستند. اطلاعات در SQLite و روی همان رایانه ذخیره می‌شوند. این بسته کد کامل و فایل اجرای کمکی دارد؛ فایل اجرایی مستقل EXE نیست.

## نسخهٔ تجاری، آیفون، اندروید و ویندوز

راهنمای کامل استقرار HTTPS، صدور و تمدید لایسنس، مدیریت دستگاه‌ها، نصب وب‌اپ آیفون و ساخت کلاینت‌های ویندوز/اندروید در **[DEPLOY-FA.md](DEPLOY-FA.md)** است.

- `commercial/`: سرور مجوز و حساب‌های جداگانه، API و رابط وب فارسی با مدیریت محصولات
- `clients/windows/` و `clients/android/`: پروژه‌های ساخت کلاینت آنلاین؛ نصب‌کنندهٔ EXE یا APK آماده و امضاشده همراه بسته نیست.
- `Dockerfile`، `compose.yaml` و `deploy/`: تنظیمات استقرار؛ هنوز روی سرور واقعی آزمایش نشده‌اند.
- نسخهٔ تجاری به سرور HTTPS و اینترنت نیاز دارد؛ نشانی نمونه باید عوض شود. فایل IPA برای آیفون تولید نشده است؛ آیفون از وب‌اپ استفاده می‌کند.
- لایسنس سروری شامل نسخهٔ محلی Python زیر نیست. کد سرور و ابزار فروشنده برای تحویل به مشتری نهایی نیستند.

## نصب در ویندوز

۱. Python نسخهٔ ۳٫۱۰ یا جدیدتر را با گزینه‌های **Add Python to PATH** و **Tcl/Tk and IDLE** نصب کنید.
۲. فایل ZIP را کاملاً از حالت فشرده خارج کنید. پوشه را در محلی قابل‌نوشتن، مانند Documents، بگذارید؛ برنامه را داخل ZIP یا Program Files اجرا نکنید.
۳. `start_windows.bat` را دوبار کلیک کنید. بار اول برای دریافت وابستگی‌ها اینترنت لازم است. اجراهای بعدی آفلاین هستند.

روش دستی در ترمینالِ پوشهٔ برنامه:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe gold_accounting.py
```

## نصب در لینوکس

برای Ubuntu/Debian:

```bash
sudo apt install python3 python3-tk python3-venv
bash start_linux.sh
```

برنامه به محیط دسکتاپ و نمایشگر نیاز دارد. برای توزیع‌های دیگر بسته‌های متناظر Python، Tk و venv را نصب کنید. نخستین اجرای فایل کمکی به اینترنت نیاز دارد.

روش دستی:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python gold_accounting.py
```

در macOS می‌توان با Python دارای Tk و دستورهای روش دستی اجرا کرد؛ این بسته روی macOS آزموده نشده است.

## راه‌اندازی اولیه و ساعت

- در نخستین اجرا، تاریخ شمسی و ساعت داخلی را تنظیم و کلید مدیریت تولیدشده را در محل امن نگهداری کنید.
- پس از تأیید، ساعت داخلی قفل می‌شود. تغییر بعدی از پنجرهٔ **مدیریت** و با کلید مجاز است.
- ساعت تنظیم‌شده، ساعت برنامه است؛ ساعت سیستم‌عامل تغییر نمی‌کند. تغییر ساعت بر تاریخ اسناد قبلی اثر ندارد.
- زمان در طول هر اجرا با شمارندهٔ یکنواخت جلو می‌رود؛ بین اجراها از زمان ثبت‌شده و ساعت رایانه استفاده می‌شود. بنابراین این سازوکار مرجع زمان مستقل یا ضد‌دستکاری مطلق نیست.
- کلید در پایگاه داده به‌صورت هش PBKDF2 ذخیره می‌شود؛ تلاش‌های ناموفق و تغییرهای مدیریتی ثبت می‌شوند. کلید جای حفاظت از فایل‌ها و حساب کاربری سیستم‌عامل را نمی‌گیرد. برای کلید گم‌شده، بازنشانی عمومی در رابط تعبیه نشده است.

## ثبت، ویرایش و حذف

در برگهٔ **ورود** یا **خروج**، نوع طلا، وزن اولیه، قیمت هر گرم و درصدهای فعال را وارد کنید. دکمهٔ «محاسبه» پیش‌نمایش می‌دهد؛ ثبت نهایی نیازمند تأیید است.

- **طلای نو / ورود:** مبلغ خام + اجرت ساخت؛ اجرت فروش و مالیات ندارد.
- **طلای نو / خروج:** اجرت ساخت روی مبلغ خام، اجرت فروش روی خام به‌اضافهٔ اجرت ساخت، و مالیات فقط روی مجموع دو اجرت محاسبه می‌شود.
- **دست‌دوم / ورود:** وزن حساب‌شده برابر وزن اولیه × ۷۳۵ ÷ ۷۵۰ است. مبلغ ورود بر همین وزن حساب‌شده محاسبه می‌شود.
- **دست‌دوم / خروج:** وزن تبدیل‌شده از موجودی قابل‌فروش کم می‌شود؛ وزن اولیه به‌اضافهٔ درصد اجرت فروش، مبنای مبلغ فروش است. اختلاف این دو وزن به‌عنوان سود طلایی جداگانه ثبت می‌شود.
- نمونهٔ دست‌دوم: ورود ۱۰ گرم، ۹٫۸ گرم موجودی ایجاد می‌کند. فروش همان ۱۰ گرم با اجرت ۵٪، ۱۰٫۵ گرم مبنای مبلغ فروش دارد و ۰٫۷ گرم سود طلایی ثبت می‌کند. این سود دوباره در موجودی قابل‌فروش شمرده نمی‌شود.
- اجرت ساخت و مالیات برای دست‌دوم اعمال نمی‌شوند.

از جدول، سند را انتخاب و گزینهٔ ویرایش یا حذف را بزنید. ویرایش شماره و تاریخ ثبت اولیه را حفظ می‌کند و زمان آخرین ویرایش جدا ثبت می‌شود. تغییر یا حذف اگر موجودی را در هر نقطه از ترتیب ثبت اسناد منفی کند، رد می‌شود. شمارهٔ سند حذف‌شده دوباره استفاده نمی‌شود.

**سوابق قدیمی:** مقادیر تاریخی و جزئیات ناموجود بازسازی یا حدس زده نمی‌شوند؛ ویرایش بدون تغییر مؤثر، مبلغ قبلی را حفظ می‌کند. تغییر ورودی‌های مؤثر، محاسبه را با قواعد فعلی انجام می‌دهد. قبل از ارتقای نسخه حتماً پشتیبان بگیرید.

## جستجو و گزارش

- جستجو به‌طور پیش‌فرض روز جاریِ ساعت داخلی را نشان می‌دهد.
- تاریخ شمسی، بازهٔ ساعت، حداقل/حداکثر وزن اولیه، شمارهٔ سند، جهت و نوع طلا را می‌توان فیلتر کرد. فیلترهای فعال هم‌زمان و با منطق «و» اعمال می‌شوند.
- برای جستجو در همهٔ روزها، محدودیت تاریخ را غیرفعال کنید. ساعت ناموجود در اسناد قدیمی جعل نمی‌شود؛ این اسناد در فیلتر ساعت قرار نمی‌گیرند.
- جستجو را اعمال کنید، سپس سند را برای نمایش جزئیات یا رفتن به برگهٔ مربوط انتخاب کنید.
- «ذخیره PDF» و «چاپ» از برگهٔ فعال گزارش می‌گیرند. در برگهٔ جستجو، آخرین نتایج اعمال‌شده مبناست؛ تغییر فیلتر بدون اعمال جستجو، گزارش را تغییر نمی‌دهد.
- PDF فارسی، صفحه‌بندی، جمع‌ها و مشخصات فیلتر دارد. پوشهٔ `assets` باید کنار فایل‌های برنامه باقی بماند.
- چاپ به چاپگر پیش‌فرض سیستم ارسال می‌شود. در لینوکس/macOS وجود `lp` یا `lpr` و چاپگر تنظیم‌شده لازم است. در ویندوز، برنامهٔ پیش‌فرض PDF باید فرمان چاپ را پشتیبانی کند. اگر چاپ مستقیم کار نکرد، PDF را ذخیره و از PDFخوان چاپ کنید.

## داده‌ها، پشتیبان و انتقال

فایل `gold_accounting.sqlite3` کنار `gold_accounting.py` ساخته می‌شود و شامل اسناد، تنظیمات ساعت، هش کلید و رویدادهای مدیریتی است. آن را حذف یا همراه نسخهٔ جدید جایگزین نکنید.

- برای پشتیبان، از پنجرهٔ مدیریت و گزینهٔ **تهیه پشتیبان کامل** استفاده کنید؛ پشتیبان با API پشتیبان SQLite تهیه می‌شود.
- برای بازیابی: برنامه را ببندید، از فایل فعلی یک نسخهٔ جدا نگه دارید، سپس پشتیبان را با نام `gold_accounting.sqlite3` کنار برنامه قرار دهید. بازیابی کل داده‌ها و تنظیمات را جایگزین می‌کند، نه اینکه اسناد را ادغام کند.
- اگر فایل‌های جانبی `-wal` یا `-shm` باقی مانده‌اند، پیش از جایگزینی پایگاه و در حالی که هیچ اجرای برنامه باز نیست، آن‌ها را نیز با نسخهٔ فعلی به پوشهٔ جدا منتقل کنید؛ فایل‌های متعلق به دو پایگاه را مخلوط نکنید.
- برای انتقال به رایانهٔ دیگر، پشتیبان کامل را منتقل کنید و همان کلید مدیریت را نگه دارید. پشتیبان حاوی داده‌های حساس است؛ در جای امن ذخیره شود.
- هم‌زمان چند نسخه از برنامه را روی یک پایگاه اجرا نکنید. این بسته برای استفادهٔ محلی تک‌کاربره تهیه شده، نه دسترسی شبکه‌ای و چندکاربره.

## عیب‌یابی

- `No module named tkinter` یا خطای Tcl/Tk: در ویندوز نصب Python را با Tcl/Tk اصلاح کنید؛ در لینوکس `python3-tk` را نصب کنید. pip به‌تنهایی Tk سیستم را نصب نمی‌کند.
- خطای `reportlab`، `arabic_reshaper` یا `bidi`: با همان Python محیط مجازی، `pip install -r requirements.txt` را دوباره اجرا کنید.
- خطای نمایشگر: برنامه را در نشست دسکتاپ اجرا کنید، نه SSH بدون نمایشگر.
- خطای دسترسی پایگاه: پوشه را به محل قابل‌نوشتن منتقل کنید.
- فایل کمکی محیط مجازی محلی `.venv` می‌سازد. اگر نصب نیمه‌کاره ماند، فقط `.venv` را حذف و فایل کمکی را دوباره اجرا کنید؛ **پایگاه داده را حذف نکنید**.

## آزمون‌ها و محتویات

```bash
python -m pip install -r requirements-dev.txt
python -m unittest -v
```

آزمون رابط به Tk و نمایشگر نیاز دارد و در محیط بدون نمایشگر رد می‌شود. در لینوکسِ دارای Xvfb:

```bash
xvfb-run -a python -m unittest -v
```

- `gold_accounting.py`: محاسبات، پایگاه و پنجرهٔ اصلی
- `gold_services.py`: جستجو، تاریخ شمسی، ساعت و مدیریت
- `gold_features.py`: داشبورد، جستجو و پنجره‌های تکمیلی
- `gold_widgets.py`: نمایش فارسی بدون تغییر رشته‌های منطقی داده‌ها
- `gold_reports.py`: PDF و چاپ
- `assets/`: فونت PDF و مجوز آن
- `test_gold_*.py`: آزمون‌ها

آزمون‌های منطق، PDF و رابط در محیط لینوکس با نمایشگر مجازی اجرا شده‌اند؛ فایل کمکی ویندوز و چاپگر فیزیکی در این محیط آزموده نشده‌اند. این برنامه جایگزین بررسی حسابدار و الزامات قانونی و مالیاتی محل فعالیت نیست.

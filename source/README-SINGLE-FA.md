# حساب قدیم — نسخهٔ دسکتاپ تک‌فایلی

فقط `hesab_ghadim_all_in_one.py` را دانلود و با Python 3.10 یا جدیدترِ دارای Tkinter اجرا کنید:

```bash
python hesab_ghadim_all_in_one.py
```

در ویندوز می‌توانید از `py -3` به‌جای `python` استفاده کنید.

- کدها و فونت داخل همین فایل هستند و در پوشهٔ `hesab_ghadim_files` کنار آن استخراج می‌شوند.
- در صورت نبود کتابخانه‌های موردنیاز، برنامه برای نصب آن‌ها از شما اجازه می‌گیرد. نصب در محیط مجازی اختصاصی انجام می‌شود و به اینترنت نیاز دارد. پس از نصب، حسابداری محلی آفلاین است.
- دانلود و نصب در اجراهای بعدی تکرار نمی‌شود، به‌شرط آنکه فایل را در همان محل اجرا کنید و پوشهٔ `hesab_ghadim_files` و محیط `.venv` داخل آن را پاک نکنید.
- در ویندوز Python را با Tcl/Tk and IDLE نصب کنید. در Ubuntu/Debian: `sudo apt install python3-tk python3-venv`.
- فایل را در پوشه‌ای قابل‌نوشتن مانند Documents ذخیره کنید؛ داخل Program Files یا پوشهٔ موقت اجرا نکنید.
- داده‌ها در `hesab_ghadim_files/gold_accounting.sqlite3` ذخیره می‌شوند. هنگام اجرای مجدد این فایل جایگزین یا پاک نمی‌شود. پوشه را حذف نکنید.
- برای انتقال اطلاعات قبلی، ابتدا برنامهٔ قبلی را ببندید و پشتیبان کامل بگیرید. برای شروع، نسخهٔ تک‌فایلی را در پوشه‌ای جدا با دادهٔ آزمایشی اجرا کنید. برای بازیابی دادهٔ واقعی از دستورالعمل بازیابی پایگاه استفاده کنید؛ فایل‌های جانبی WAL/SHM را با پایگاه دیگری مخلوط نکنید.
- برای پشتیبان‌گیری از گزینهٔ تهیهٔ پشتیبان کامل در مدیریت استفاده کنید. فقط یک اجرای برنامه را روی هر پایگاه باز نگه دارید.
- کدهای استخراج‌شده هنگام اجرای دوباره با نسخهٔ درون فایل هماهنگ می‌شوند؛ ویرایش‌های شخصی کدها را در پوشه‌ای دیگر نگه دارید. پایگاه داده و محیط مجازی جزو محتویات استخراج‌شده نیستند.

## اطلاعات کالا و عیار

در فرم ورود، «نوع/عنوان کالا» و «کد کالا» قابل ثبت‌اند. کد جدید محصول می‌سازد و کد موجود باید با نوع و عنوان همان محصول سازگار باشد. خروج کالا نمی‌تواند بیشتر از موجودی همان کد باشد.

عیار اولیه با پیش‌فرض ۷۵۰ و عیار خرید با پیش‌فرض ۷۳۵ قابل تغییرند (بزرگ‌تر از صفر و حداکثر ۱۰۰۰). برای طلای دست‌دوم، وزن محاسباتی برابر است با **وزن واردشده ÷ عیار اولیه × عیار خرید**؛ مثلاً ۱۰ گرم با پیش‌فرض‌ها، ۹٫۸ گرم می‌شود. وزن تبدیل‌شده فقط مبنای مبلغ خرید است؛ موجودی طلای دست‌دوم با وزن واقعی واردشده افزایش می‌یابد و هنگام خروج نیز وزن واقعی از موجودی کم می‌شود. سوابق قبلی خودکار تغییر نمی‌کنند. این تبدیل برای طلای نو اعمال نمی‌شود.

عیارها برای هر سند ذخیره می‌شوند؛ ارتقا، اسناد قدیمی را باز‌محاسبه نمی‌کند.

## نمایش فارسی

در حالت خودکار، ویندوز و macOS از نمایش بومی سیستم و لینوکس از شکل‌دهی دستی استفاده می‌کنند. این تغییر فقط برای نمایش است؛ متن ذخیره‌شده، کلید مدیریت، تاریخ و مقادیر ورودی تغییر نمی‌کنند.

اگر حروف جدا یا ترتیب کلمات نادرست است، برنامه را ببندید و حالت دیگر را آزمایش کنید:

```bash
python hesab_ghadim_all_in_one.py --text-mode native
python hesab_ghadim_all_in_one.py --text-mode manual
```

برای اجرای مستقیم `gold_accounting.py`، متغیر محیطی `HESAB_GHADIM_TEXT_MODE` را روی `native` یا `manual` تنظیم کنید. حالت خودکار `auto` است. حالت انتخابی خط فرمان فقط برای همان اجرا اعمال می‌شود. نمایش بومی هنوز روی ویندوز واقعی آزمایش نشده است.

## بررسی و آزمون

```bash
python hesab_ghadim_all_in_one.py --check
python hesab_ghadim_all_in_one.py --test
```

`--check` بدون نصب کتابخانه و بدون بازکردن پنجره، صحت بسته و دسترسی به کتابخانه‌ها را بررسی می‌کند؛ فایل‌های برنامه را استخراج می‌کند. تست‌های GUI به نمایشگر نیاز دارند. `--extract-only` فقط کدها را استخراج می‌کند. با `--data-dir PATH` می‌توانید پوشهٔ داده و کدها را انتخاب کنید؛ این گزینه ساعت یا داده‌های قبلی را خودکار منتقل نمی‌کند.

این نسخه شامل حسابداری محلی، ورود و خروج نو/دست‌دوم، اجرت و مالیات، موجودی و سود طلایی، اسناد، جستجو، تاریخ شمسی، گزارش PDF و اصلاح نمایش فارسی است. مبالغ تومان و وزن‌ها گرم هستند؛ مالیات فقط روی اجرت ساخت و فروش است.

**این فایل نسخهٔ تجاری سروری نیست:** رابط مدیریت کد و عنوان محصول، لایسنس سروری، وب‌اپ آیفون و کلاینت‌های اندروید/ویندوزِ متصل به سرور در پروژهٔ تجاری جدا قرار دارند. فایل تک‌فایلی EXE یا APK نیست و حفاظت سروری روی داده‌های محلی اعمال نمی‌کند. چاپگر و سیستم‌عامل هدف باید جداگانه آزمایش شوند.

ساخت نصاب با GitHub Actions

این بسته را از ZIP خارج کنید و محتوای آن را در ریشه یک مخزن خصوصی GitHub بارگذاری کنید. فایل‌های اطلاعات مشتری، دیتابیس، پیوست و پشتیبان را بارگذاری نکنید.

در ریشه مخزن باید source و setup.iss و مسیر .github/workflows/windows-installer.yml وجود داشته باشد؛ نه داخل یک پوشه اضافی.
اگر بارگذاری با مرورگر پوشه مخفی .github را نپذیرفت، در مخزن Add file > Create new file را بزنید و نام کامل .github/workflows/windows-installer.yml را وارد کنید. سپس محتوای همین فایل موجود در بسته را کپی و Commit کنید.

پس از ثبت فایل‌ها، به Actions بروید. در صورت نیاز Actions را برای مخزن فعال کنید.
Build Windows Installer > Run workflow > Run workflow را بزنید.
پس از سبز شدن اجرا، آن را باز کنید و در قسمت Artifacts فایل HesabGhadim-Setup-Win10 را دانلود کنید.
ZIP دانلودشده را باز کنید؛ فایل HesabGhadim-Setup-Win10.exe داخل آن نصاب است.

این گردش کار در این محیط اجرا نشده است. ساخت موفق به معنی آزمایش رابط و چاپ روی ویندوز نیست. خروجی امضای دیجیتال ندارد و ممکن است SmartScreen هشدار بدهد. در مخزن خصوصی مصرف Actions تابع سهمیه حساب شماست؛ قبل از اجرا سهمیه را بررسی کنید.
برای حفظ اطلاعات و انتقال از نسخه قبلی، README-FA.txt را بخوانید. ابتدا با کپی داده‌ها آزمایش کنید.

بسته ساخت نصاب ویندوز ۱۰ (هنوز روی ویندوز ساخته و آزمایش نشده)

۱. Python 3.12 نسخه ۶۴ بیتی با Tcl/Tk و Python Launcher نصب کنید.
۲. Inno Setup 6 را از https://jrsoftware.org/isdl.php نصب کنید.
۳. بسته را از ZIP خارج کنید و BUILD-WINDOWS.bat را دوبار کلیک کنید. اینترنت برای دریافت کتابخانه‌های ساخت لازم است.
۴. در صورت موفقیت، فایل output/HesabGhadim-Setup-Win10.exe نصاب نهایی است.
کاربر نهایی به Python یا اینترنت برای نصب نیاز ندارد.

اطلاعات نسخه نصبی در %LOCALAPPDATA%\HesabGhadim\hesab_ghadim_files ذخیره می‌شود و حذف برنامه آن را پاک نمی‌کند.
اطلاعات نسخه قدیمی خودکار منتقل نمی‌شوند. ابتدا برنامه قدیمی را ببندید و از کل پوشه hesab_ghadim_files نسخه پشتیبان بگیرید. برای انتقال، پس از یک بار اجرا و بستن نسخه نصبی، محتویات پوشه قدیمی را در مسیر اطلاعات بالا کپی کنید (به‌خصوص فایل gold_accounting.sqlite3 و پیوست‌ها). نسخه قدیمی و جدید را همزمان باز نکنید.
پوشه قدیمی را حذف نکنید. قبل از استفاده واقعی، نمایش فارسی، محاسبات، چاپ و پیوست‌ها را روی یک کپی داده آزمایش کنید.
